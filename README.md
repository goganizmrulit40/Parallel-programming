# Лабораторная работа №5
# Работа на суперкомпьютере «Сергей Королёв»

## 1. Задание:
Запуск параллельной MPI-программы умножения матриц на кластерной системе «Сергей Королёв» (СГАУ)

## 2. Характеристики системы
|Параметр|	Значение|
|--------|-----------|
|Суперкомпьютер	|«Сергей Королёв», СГАУ|
|Логин-узел	|login2|
|Вычислительные узлы|	n[239-240] (2 узла)|
|Процессов на узел|	4|
|Всего процессов MPI	|8|
|Компилятор	|Intel MPI Compiler (mpiicpc)|
|Версия Intel Parallel Studio	|XE 2016 (build 460803)|
|Планировщик	|Slurm|
|Утилиты	|sbatch, squeue, scancel|

## 3. Порядок выполнения работы
1) Подключимся к кластеру:
  ``` bash
login as: 2025-00007
2025-00007@sk.ssau.ru's password:
```
2) После этого через mkkdir создадим рабочую директорию.
3) Создадим файл main.cpp с кодом из 3 л.р.
4) Генерируем матрицы
5) Настроем окружение Intel:
  ``` bash
source /soft/intel/parallel_studio_xe_2016.3.067/bin/psxevars.sh intel64
```
6) Скомпилируем нашу программу:
  ``` bash
mpiicpc -O3 -std=c++11 main.cpp -o matrix_mpi
```
7) Создадим скрипт submit_job.sh для slurm:
  ``` bash
#!/bin/bash
#SBATCH --job-name=My_Job
#SBATCH --time=00:10:00
#SBATCH --nodes=2
#SBATCH --ntasks-per-node=4
#SBATCH --partition=batch
#SBATCH --output=slurm-%j.out

source /soft/intel/parallel_studio_xe_2016.3.067/bin/psxevars.sh intel64
mpirun ./matrix_mpi
```
8) Запустим задачу в очередь:
 ``` bash
sbatch submit_job.sh
```
9) Мониторим выполнение:
 ``` bash
squeue -u 2025-00007
```
10) Получаем результаты:
