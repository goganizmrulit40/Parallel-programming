# Лабораторная работа №5
# Работа на суперкомпьютере «Сергей Королёв»

## 1. Задание:

|Вычислительные узлы|	n[239-240] (2 узла)|
|Процессов на узел|	4|
|Всего процессов MPI	|8|
|Компилятор	|Intel MPI Compiler (mpiicpc)|
